# 📌 O que é Python?

Python é uma linguagem de programação muito usada no mundo inteiro.  
É conhecida por ser simples, fácil de aprender e poderosa.

Python pode ser usado para:
- 🌐 Websites
- 🤖 Inteligência Artificial
- 📊 Data Science
- ⚙️ Automação
- 🎮 Jogos

# 🧠 Variáveis

As variáveis servem para guardar informações.

```python
nome = "João"
idade = 17

print(nome)
print(idade)
```

---

# 🔢 Tipos de dados

```python
texto = "Python"

ativo = True
```

# ➕ Operadores

```python
a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)
```

---

# ❓ Condições

As condições verificam se algo é verdadeiro.

```python
idade = 18

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```

---

# 🔁 Loops

Os loops repetem código várias vezes.

## For Loop
```python
for i in range(5):
    print(i)
```

## While Loop
```python
contador = 0

while contador < 5:
    print(contador)
    contador += 1
```

---

# 📋 Listas

As listas guardam vários valores.

```python
frutas = ["maçã", "banana", "uva"]

print(frutas[0])
```

# ⚙️ Funções

As funções ajudam a organizar o código.

